How to Use the Course Config Editor

This documentation will teach you how to use the editor.html tool to safely add subjects, chapters, videos, and resources to your learning platform without writing any code.

1. Getting Started 2. Adding Subjects 3. Chapters & Videos 4. Resources 5. Saving & Exporting Open Editor Now

1. Getting Started

Loading an Existing File

If you already have a configuration file (like class6.json or class7.json), you can load it directly into the editor to make changes.

  • Drag and Drop: Simply grab the JSON file from your computer folder, drag it into the web browser, and drop it anywhere on the editor page.
  • Browse Files: Click the "Open File" button in the top navigation bar to locate the file via a standard file picker.

Starting from Scratch

If you are building a completely new class schedule (e.g., Class 8) and don't have a file yet, click the "New" button in the navigation bar. This gives you a blank canvas to start adding your subjects.

2. Adding a Subject Block

A "Subject Block" represents a specific subject (like Mathematics) taught in a specific language (like English) for a specific class grade.

To add a new subject, scroll down and click the green "+ Add New Subject Block" button.

Fill in the following essential fields:

  • Class: The grade level (e.g., "6", "7").
  • Subject: The name of the subject (e.g., "Science", "Mathematics").
  • Medium: Use the dropdown to select "English" or "Telugu". This is crucial! Platform progress tracking relies on this being accurate to keep separate scores for different mediums.

Course Overview

Each subject can have an overview. Click "+ Add Course Overview" to provide a brief description and the estimated duration of the course (e.g., "Full Year"). This gives students a summary before they start.

3. Adding Chapters and Videos

Inside each Subject Block, you organize your learning content chronologically into Chapters. Inside Chapters, you put your individual Video Lessons.

Adding a Chapter

Click the blue "Add Chapter" button inside your Subject Block. You can type the name of the chapter directly into the "Chapter Name" box (e.g., "Fractions and Decimals").

Adding Videos (Subtopics)

Inside the chapter box on the left, click the green "Add Video" button to insert a new lesson.

  • Video Name: What the student will see in the sidebar list (e.g., "Introduction to Fractions").
  • Description: The detailed text shown directly below the video player.
  • YouTube Embed Link: The video URL. Important: You must use the Embed URL format provided by YouTube (e.g., https://www.youtube.com/embed/XCGoZBj9hdE), not the standard watch link.

4. Adding Study Resources

You can attach extra materials to a chapter, such as downloadable PDF notes, homework assignments, or external website links.

Inside the chapter box (on the right side), click the teal "Add Resource" button.

  • Resource Name: The label for the button the student clicks (e.g., "Chapter 1 Notes", "Practice Problems").
  • Link/URL: The direct web link to the PDF file or HTML page.
  • Type: Use the dropdown to select if it is a PDF Document or an HTML Link. This ensures the platform shows the correct icon (a PDF logo vs a Globe).

5. Saving and Applying Changes

Important: The editor is a secure, offline-capable tool. It does not hack your website to save changes automatically. You must manually download the updated file to apply the changes to the live site!

As you type, the dark Live JSON Preview box on the right side of the screen updates automatically. When you are totally finished editing:

  1. Check the filename text box in the top navigation bar (it will usually say class6.json). You can rename it if necessary (e.g. class8.json).
  2. Click the yellow "Download Updated JSON" button.
  3. The file will be downloaded to your computer's default "Downloads" folder.
  4. Open your project files and drag that downloaded file into the config/ folder, replacing the old file of the same name.
  5. Refresh your main platform page, and your new content will instantly be available to students!
